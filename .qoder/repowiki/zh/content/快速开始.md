## 简介
本指南面向新开发者，帮助你在最短时间内成功运行 HotClaw 项目。HotClaw 是一个基于多智能体协作的微信公众号内容生产平台，包含后端 FastAPI 服务与前端 Next.js 应用。你将学会：
- 环境准备（Python 3.11+、Node.js、数据库等）
- 项目克隆与依赖安装
- 环境变量配置
- 本地开发环境启动（后端 + 前端）
- Docker 容器化部署方案
- 常见问题与故障排除

## 项目结构

## 架构概览
系统采用“前后端分离 + SSE 实时推送”的设计。前端通过 /api/* 代理访问后端，后端通过 SSE 将任务节点状态推送给前端，实现可视化运行链路。

```mermaid

BE --> REDIS["Redis 缓存"]
BE --> LLM["LLM API"]

SSE --> FE
```

## 故障排除指南
- Python 版本不满足要求
  - 现象：启动脚本报错，提示需要 Python 3.11+
  - 解决：安装 Python 3.11+ 并重新运行启动脚本
- Node.js 版本不满足要求
  - 现象：前端无法启动或报错
  - 解决：安装 Node.js 18+ 并重新安装依赖
- 数据库连接失败
  - 现象：后端启动时报数据库错误
  - 解决：确认数据库 URL 设置正确（开发默认 SQLite，生产使用 PostgreSQL）
- Redis 连接失败
  - 现象：后端启动时报 Redis 连接错误
  - 解决：确认 Redis 地址与端口正确，或在环境中调整配置
- 前端无法访问后端 API
  - 现象：页面无法获取数据或报跨域错误
  - 解决：确认前端 next.config.ts 的 /api/* 代理已启用，后端已启动
- 启动脚本无法执行
  - 现象：Windows 下 .bat 无法运行，Linux/macOS 下 .sh 无权限
  - 解决：授予执行权限或使用管理员权限运行
